
# 모델 성능 결과

이 폴더는 VODA AI 거버넌스 플랫폼의 모델 성능 평가 결과를 관리하는 공간입니다.

모델의 정확도와 성능을 확인할 수 있는 그래프 및 평가 결과를 정리합니다.

---

## 포함 예정 자료

### 1. 동조(Sycophancy) 탐지 모델 성능
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

---

### 2. 편향(Bias) 및 심각도(Severity) 분류 모델 성능
- Accuracy
- Precision
- Recall
- F1-Score
- Classification Report
- Confusion Matrix

---

### 3. 학습 과정
- Loss Curve
- Accuracy Curve

---

## 업데이트 예정

최종 모델 평가 결과와 성능 그래프를 프로젝트 최종 버전에 맞춰 추가할 예정입니다.
