# 모델 성능 평가

이 폴더는 **VODA AI 거버넌스 플랫폼**에 적용된 모델의 성능 평가 결과와 오차 분석 자료를 관리하는 공간입니다.

프로젝트에서는 KcELECTRA 기반 모델을 활용하여 AI 응답의 동조 여부, 편향 수준 및 심각도를 분석하였으며, 별도의 테스트 데이터와 예외 사례를 통해 모델 성능을 검증했습니다.

---

## 평가 대상

### 1. 동조 탐지 모델

사용자의 편향된 주장에 AI가 동의하거나 편승하는지를 이진 분류합니다.

평가 항목

- Accuracy
- Precision
- Recall
- F1-Score
- Macro F1
- 오분류 사례 분석
- 개시어가 없는 문장에 대한 Trap Test

단순히 `네`, `맞습니다` 등의 표현만 탐지하는 것이 아니라, 명시적인 동의 표현 없이 편향에 동조하는 문장과 중립적·반박형 문장을 구분할 수 있는지 추가로 검증했습니다.

---

### 2. 편향 및 심각도 분류 모델

AI 응답에 포함된 편향 수준과 윤리적 위험도를 다중 분류합니다.

평가 항목

- Accuracy
- Precision
- Recall
- F1-Score
- Macro Average
- Weighted Average
- Classification Report
- Confusion Matrix
- 클래스별 TP, FP, FN, TN 분석

혼동 행렬과 클래스별 평가 지표를 활용해 정상 응답, 욕설성 응답, 편향 응답 간 오분류 유형을 분석했습니다.

---

## 평가 방법

모델 성능 평가는 별도로 분리한 테스트 데이터셋을 사용하여 진행했습니다.

평가 과정은 다음과 같습니다.

1. 테스트 데이터 전처리
2. 학습 완료 모델 로드
3. 배치 단위 모델 추론
4. 실제 레이블과 예측 레이블 비교
5. 분류 리포트 및 혼동 행렬 생성
6. 오분류 사례 확인
7. 예외 문장 및 Trap Test 수행

---

## 주요 검증 내용

- 동조 표현이 명시되지 않은 문장에서도 동조 여부를 구분할 수 있는지 확인
- 단순 키워드 기반 판단과 실제 모델 결과 비교
- 편향 수준별 오분류 패턴 분석
- 클래스 불균형을 고려한 Macro F1 확인
- 실제 서비스 상황을 가정한 예외 입력 검증
- 정상 문장과 욕설·편향 문장의 혼동 여부 점검

---

## 관련 파일

프로젝트의 성능 평가 및 오차 분석은 다음 자료를 기반으로 진행했습니다.

- `성능_평가_및_오차분석.ipynb`
- 편향 및 심각도 모델 체크포인트
- 동조 탐지 모델 체크포인트
- 전처리된 학습·검증·테스트 데이터
- 통합 플랫폼 노트북
- SQLite 분석 결과 데이터베이스

---

## 평가 결과 활용

성능 평가 결과는 단순히 모델 정확도를 확인하는 데 그치지 않고 다음 과정에 활용했습니다.

- 모델의 취약한 입력 유형 확인
- 오분류 원인 분석
- 임계값 및 판단 기준 보완
- 통합 플랫폼의 분석 결과 검증
- 실제 시연 질문 및 예외 사례 선정
- 향후 모델 개선 방향 도출
